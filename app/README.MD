# Запуск приложения

## 1. Установить зависимости

Выполняется при первом запуске или после изменения `requirements.txt`:

```bash
./scripts/setup-app.sh
```

## 2. Активировать виртуальное окружение

Выполняется в каждом новом терминале:

```bash
source .venv/bin/activate
```

## 3. Запустить один экземпляр с настройками по умолчанию

```bash
python app/main.py
```

По умолчанию приложение использует:
  * порт 3000;
  * идентификатор экземпляра default.

## 4. Запустить экземпляр на произвольном порту

```bash
PORT=4100 INSTANCE_ID=backend-1 python app/main.py
```

Переменные перед командой действуют только для запускаемого процесса:

  * PORT — порт экземпляра;
  * INSTANCE_ID — имя экземпляра.

## 5. Запустить несколько экземпляров

Первый терминал:

```bash
source .venv/bin/activate
PORT=4100 INSTANCE_ID=backend-1 python app/main.py
```

Второй терминал:

```bash
source .venv/bin/activate
PORT=7200 INSTANCE_ID=backend-2 python app/main.py
```

Количество экземпляров заранее не ограничено, но каждый должен использовать свободный порт.

## 6. Проверить экземпляры

```bash
curl http://127.0.0.1:4100/api/health
curl http://127.0.0.1:4100/api/info

curl http://127.0.0.1:7200/api/health
curl http://127.0.0.1:7200/api/info
```

### СКРИПТ для нахождения и проверки всех локальных экземпляров

```bash
./scripts/discover-app.sh
echo $?
```
